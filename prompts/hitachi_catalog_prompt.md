# 日立エアコン「白くまくん」カタログ用 Gemini チャットプロンプト

非エンジニアやビジネスユーザーが **Gemini Web UI (gemini.google.com)** や **Google AI Studio** のチャット画面に日立エアコンの製品一覧カタログ画像をアップロードし、以下のプロンプトをコピペして実行することで、**メーカー名・製品カテゴリー属性付きの構造化JSON (catalog_models_aircon_hitachi.json)** を出力できます。

---

## 📋 使い方手順 (ビジネスユーザー向け)

1. **Gemini チャットUIを開く**
   - [Gemini](https://gemini.google.com) または [Google AI Studio](https://aistudio.google.com) にアクセスします。
2. **日立エアコンのカタログ画像をアップロードする**
   - ＋ボタンや画像添付から、抽出したい日立エアコンのカタログ画像（「白くまくん」製品一覧ページ）を添付します。
3. **プロンプトをコピペして送信する**
   - 下記の「コピペ用プロンプト」を全文コピーしてプロンプト入力欄に貼り付け、送信します。
4. **JSONデータをコピーして保存する**
   - 出力された JSON コードブロックの右上にある **「コピー」ボタン** をクリックし、`catalog_models_aircon_hitachi.json` として保存します。

---

## 💬 コピペ用プロンプトテンプレート (日立エアコン用)

> 以下の点線内をすべてコピーして Gemini に送信してください。

```text
添付された日立エアコン「白くまくん」のカタログ画像から、掲載されているすべての型番について、以下の抽出ルールとJSONフォーマットに従って型番単位の構造化JSONを出力してください。

【抽出ルール】
1. メーカー・カテゴリー情報 (manufacturer / product_category / brand_name):
   - manufacturer: "日立"
   - product_category: "壁掛形ルームエアコン"
   - brand_name: "白くまくん" または "メガ暖 白くまくん"
2. 型番 (model_number):
   - 掲載されているすべての型番（例: RAS-X2226S, RAS-XR4026D, RAS-XK2526S など）を1つも漏らさずに抽出してください。
3. シリーズ名 (series_name):
   - 各型番が属するシリーズ名 (Xシリーズ, Wシリーズ, Gシリーズ, Dシリーズ, Eシリーズ, XKシリーズ, RKシリーズ) を抽出してください。
4. ユニークセリングポイント (unique_selling_point):
   - 各シリーズヘッダー部分にある説明文章テキスト（キャッチコピー）を抽出し、そのシリーズ内の全型番に付与してください。
5. 価格・省エネ達成率 (price):
   - 省エネ基準達成率 (例: 110%) とオープン価格表記を抽出してください。
6. 主なおすすめ機能 (recommended_features):
   - ページ下部の機能比較表を参照し、該当シリーズの列で背景色・チェック・文字記載がある項目を機能カテゴリごとに配列として抽出してください。
